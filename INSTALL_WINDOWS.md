# Instalación física en Windows

## Destino propuesto

```text
D:\NZXTG7\GYPPORT\GYPPORT ERP\GYPPORT\Fabric
```

## Procedimiento

1. Cerrar cualquier proceso que use la carpeta de destino.
2. Si ya existe `Fabric`, no sobrescribirla: comparar primero su contenido.
3. Copiar o extraer el paquete de forma que `AGENTS.md` quede directamente
   dentro de `Fabric`.
4. Abrir `Fabric` como espacio de trabajo.
5. verificar `README.md`, `AGENTS.md` y `.chatgpt/CURRENT_STATE.md`.
6. Crear una copia fechada en NAS o disco secundario.
7. Importar fuentes únicamente después de registrar el alcance.

## Verificación visual

La ruta final esperada de un archivo canónico es:

```text
D:\NZXTG7\GYPPORT\GYPPORT ERP\GYPPORT\Fabric\.chatgpt\CURRENT_STATE.md
```

No debe quedar una carpeta duplicada como `Fabric\Fabric\`.
