# Continuidad explícita de GYPPORT®

Esta carpeta conserva contexto recuperable en archivos. No reemplaza ni
sincroniza automáticamente la memoria de ChatGPT.

| Archivo o carpeta | Función |
|---|---|
| `PROJECT_CONTEXT.md` | Identidad, alcance y arquitectura estable |
| `CANONICAL_MEMORY.md` | Hechos duraderos verificados |
| `CURRENT_STATE.md` | Estado operativo vigente |
| `DECISION_REGISTER.md` | Decisiones expresamente aprobadas |
| `UNRESOLVED_REGISTER.md` | Bloqueos y preguntas abiertas |
| `continuity-packets/` | Reanudación de conversaciones extensas |
| `checkpoints/` | Estado acumulativo por track |
| `conversation-summaries/` | Resúmenes controlados |
| `conversation-exports/` | Exportaciones privadas, excluidas de Git |
| `approved-prompts/` | Prompts aprobados |
| `working-prompts/` | Prompts todavía no aprobados |
| `archive/` | Material sustituido con trazabilidad |
