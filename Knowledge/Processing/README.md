# Procesamiento del conocimiento

El procesamiento se realiza por lotes acumulativos. Inventariar una fuente no
autoriza a declararla procesada.

Cada lote debe producir:

- estado de fuentes;
- unidades `KN-xxxxxx`;
- matrices actualizadas;
- contradicciones;
- asuntos no resueltos;
- checkpoint;
- evidencia del alcance.
