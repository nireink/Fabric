# Fuentes originales

Guardar aquí libros, normativa, datos públicos, documentos internos y material
multimedia. Esta carpeta está excluida de Git por defecto.

Antes de procesar una fuente:

1. asignar `SRC_ID`;
2. registrar procedencia;
3. calcular hash;
4. identificar duplicados y variantes;
5. verificar accesibilidad;
6. clasificar sensibilidad y restricciones de uso.
