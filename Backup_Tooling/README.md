# Respaldo y recuperación

Objetivo mínimo:

```text
COPIA_1=PC_LOCAL
COPIA_2=QNAP_O_DISPOSITIVO_SECUNDARIO
COPIA_3=REPOSITORIO_PRIVADO_O_BACKUP_CIFRADO
```

Las carpetas `scripts/`, `restore-procedures/` e `integrity-checks/` quedan
reservadas para herramientas revisadas. Ningún script de respaldo o
restauración se ejecuta automáticamente.
